## ♻️ Smart Waste Segregator

### AI × Computer Vision × Robotics × IoT

My primary/current project — an intelligent system designed to identify and physically segregate different categories of waste.

```text
                         CAMERA
                            │
                            ▼
                    ┌──────────────┐
                    │ AI DETECTION │
                    │ YOLO / CV    │
                    └──────┬───────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │ CLASSIFICATION  │
                  │ + CONFIDENCE    │
                  └────────┬────────┘
                           │

                  ┌─────────────────┐
                  │ CONVEYOR        │

                  └────────┬────────┘
                           │

                  ┌─────────────────┐
                  │ HARDWARE CONTROL│
                  │ Arduino / RPi   │
                  └────────┬────────┘
```

* Confidence gating
* Conveyor tracking
* Raspberry Pi
* Arduino
* IR sensors
* Inductive sensing

* FastAPI
* React / Vite
